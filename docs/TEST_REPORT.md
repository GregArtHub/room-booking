## Backend: unit-тесты сервисного слоя (75)


**`backend/src/auth/auth.service.spec.ts`**

- возвращает 409, если email занят
- хранит пароль только в виде хэша и не возвращает его
- отклоняет неверный пароль (401)
- отклоняет неизвестный email одинаковой ошибкой
- не пускает заблокированного пользователя (403)
- выдаёт пару токенов и хранит только хэш refresh-токена
- отклоняет неизвестный токен
- отклоняет отозванный и просроченный токены
- ротирует токен: старый отзывается, выдаётся новая пара
- для неизвестного email ничего не создаёт и не падает
- для известного email создаёт одноразовый токен
- сброс по неверному токену даёт 400
- сброс по верному токену меняет пароль и отзывает сессии
- отзывает refresh-токен пользователя

- создаёт бронь и отправляет уведомления
- запрещает изменять чужую бронь (403)
- возвращает 404 для несуществующей брони
- запрещает менять начавшуюся бронь
- запрещает менять отменённую бронь
- обновляет бронь владельца и уведомляет
- не считает саму бронь конфликтом при проверке пересечений

- сотрудник не может отменить чужую бронь

## Backend: интеграционные тесты API (реальная БД) (15)


**`backend/test/app.e2e-spec.ts`**

- регистрация: повторный email даёт 409 в едином формате ошибки
- регистрация: невалидные данные дают 400 с деталями по полям
- вход: неверный пароль даёт 401, верный выдаёт токены, refresh ротирует токен

- сотрудник не может получить список пользователей (403), администратор может

- availability показывает занятые слоты
- сотрудник не видит и не отменяет чужие брони, видит только свои
- владелец отменяет бронь, и слот освобождается
- администратор получил уведомления о действиях сотрудников
- дашборд доступен администратору и недоступен сотруднику
- заблокированный пользователь не может войти и теряет доступ

## Как запускать

```bash
cd backend  && npm run test:cov      # unit-тесты + покрытие (порог 60% в package.json)
cd backend  && npm run test:e2e      # интеграционные (нужна БД: DATABASE_URL и prisma migrate deploy)
cd frontend && npm test              # тесты компонентов
```
